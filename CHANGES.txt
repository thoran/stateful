1.0.2: Fix non-deterministic event ordering.

    (aka The 'Don't try to push out changes while the dog is hassling you to take them for a walk!' Edition)

    1. ~ lib/Stateful/State.rb (non_deterministic_event_ordering?): Fixed logic bug where (@options[:deterministic] && !@options[:deterministic])  always evaluated to false.  Changed to @options.key?(:deterministic) && !@options[:deterministic].

    4. ~ lib/Array/shuffle.rb: Removed.  Ruby stdlib has provided Array#shuffle since 1.8.7 and gemspec requires >= 2.5.
    5. ~ lib/Stateful/State.rb: Removed require_relative for lib/Array/shuffle.rb.
    6. ~ test/ActiveRecord/WithPersistenceSpecificExtend.rb: Fixed delete_all guard to check 'active_record_machine2s' instead of 'active_record_machine1s'.
    7. ~ test/ActiveRecord/WithMultipleFinalStates.rb: Fixed comment header (was Poro/WithMultipleFinalStates.rb).
    8. ~ test/Poro/WithVariableName.rb: Fixed comment header (was ActiveRecord/WithVariableName.rb).
    9. ~ test/Poro/WithExplicitNonDeterministicEventOrdering.rb: Changed transition order assertions to use must_include instead of must_equal.
    10. ~ test/ActiveRecord/WithExplicitNonDeterministicEventOrdering.rb: Same as above.
    11. ~ test/ActiveRecord/WithExplicitGlobalNonDeterministicEventOrdering.rb: Same as above.
    12. ~ test/ActiveRecord/WithExplicitGlobalNonDeterministicEventOrderingAndInitialStateBlock.rb: Same as above.
